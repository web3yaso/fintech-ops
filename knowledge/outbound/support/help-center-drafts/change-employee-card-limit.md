# How do I change the monthly spend limit on an employee card?
**DRAFT help-center article — from 7 identical tickets, median 8.7h each. Deflects ~61h/quarter.**

1. **Cards → select the card → Limits**
2. Set the new monthly limit and **Save** — changes apply immediately
3. Admins can also set per-transaction caps in the same panel
Only account admins can change limits. The cardholder gets a notification.
